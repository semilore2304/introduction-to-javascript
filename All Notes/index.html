1. Introduction to the Web Brief history of the Web The Web, also called the World Wide Web or WWWW, was invented by Tim Berners-Lee in 1989 while he was working at CERN. It was initially created to help researchers share and connect information. It has since developed into a system of connected webpages and digital resources that users access through the Internet with browsers such as Google Chrome, Mozilla Firefox, Safari and Microsoft Edge. Simple distinction: The Internet is the worldwide network connecting computers and devices. The Web is one service that uses the Internet to provide linked webpages and resources. 1.1 What is web development? Web development is the process of creating websites and web applications. It includes building what users see and the systems that work behind the scenes. Examples include social-media websites, search engines, school portals, banking applications and online stores. 1.2 How the Web works: client-server sequence Websites are stored on special computers called servers. A browser acts as a client because it requests resources from a server. The user enters a URL or selects a link. The browser sends an HTTP request to the server. The server receives and processes the request. The server sends an HTTP response containing the webpage resources. The browser reads the HTML, CSS and JavaScript. The browser renders the visual webpage. Real-world analogy: Think of the process as a restaurant. The customer is the user, the waiter is the browser, the order is the request, the kitchen is the server and the prepared meal is the response. How websites work A website is a collection of related webpages hosted on a server. When a user enters a URL, the browser requests the required resources. The server responds, and the browser combines the HTML, CSS, JavaScript and media to display the page. Frontend - the part users see and interact with. Backend - the system/systems working behind the scenes. Restaurant website example: the displayed menu and order form are frontend features; storing the order, checking availability and calculating the total are backend operations. The three core Web technologies - HTML, CSS and Javascript. HTML - Structures and describes webgage content. CSS - Controls appearance, spacing and layout. Javascript - Adds functionality, interactivity/behaviour. What is HTML? HTML stands for HyperText Markup Language. It is the foundation of a webpage and defines content such as headings, paragraphs, links, images, lists, tables and forms. Key characteristics of HTML Structure: HTML provides the basic structure of a webpage. Markup language: HTML uses tags to mark up and describe content. Not a programming language: HTML does not provide general programming logic such as loops and conditions. Document format: HTML files are text documents that normally end with the .html extension. Web standard: modern HTML is developed as a living standard and interpreted by web browsers (HTML5). Key idea: HTML is the backbone of a webpage.
